This is where my public text code begins, and where a pattern sets that never breaks: _I learn by building real software and publishing it, at a pace that embarrasses adults._ In **March 2021** I pushed **nodejs-notebook** to npm, my first package. A month later came **minecraft.js**, an API wrapper written like a library instead of a script, and **MoreSurvival**, a Bukkit plugin. I was _twelve_.

::insight{icon="i-lucide-quote" title="The Moment It Clicked"}
"I got my first 5-star review, and moved forward."
::

:::more{title="2021, Read Closely"}
**QuantumPen**, a packet-level world editor, became my first published plugin on SpigotMC. The code was what you would expect from a self-taught kid: single-module Maven builds, copy-pasted boilerplate, a getter that returned the wrong field, and commits literally titled _"replit updates"_ because I worked in a browser IDE. It had **zero tests and zero documentation**.

I used to call 2021 the start of everything. The history says otherwise. **SMPCore**, a plugin from July 2021, has 96 Java files in its very first commit, so I had written it somewhere GitHub never saw. The date I started plugin work is unknown, and I am not going to guess one. The accurate claim is that a large Java plugin existed when I was thirteen, and what changed in 2022 was that the work became reusable, with tests, strangers' users and public releases.
:::
