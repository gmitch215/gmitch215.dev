In 2023 I stopped building only applications and started building tools that build applications. **InceptusNMS** is my own documentation engine, a Kotlin parser that turns JSON schema files into a browsable site in the style of the JDK Javadoc. **KotlinMC** automated my own distribution with an hourly job that polls JetBrains, bumps a Gradle plugin and publishes to Modrinth. I was _fifteen_. That summer GamerCoder also became Gregory Mitchell, then **gmitch215**.

::insight{icon="i-lucide-quote" title="Why I Rebranded"}
"I was getting older and needed to be more professional. I wanted a name that reflected my identity as a developer, not just a gamer."
::

:::more{title="The Name"}
My git display name flipped to my real name across every active repo in June and July of 2023, and the handle followed in 2024. The new name is _g_ plus _mitch_ plus _215_, a number I picked at eleven and am honest about not caring much about.

I then bought `gmitch215.xyz` and later `.dev`, `.fun` and `.blog`. I like `.xyz` mostly because it is the only top-level domain I can get cheap in the first year.
:::
