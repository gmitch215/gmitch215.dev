2024 opened with the most advanced thing I ever built in Minecraft, then pivoted hard toward _range_. **SocketMC** pairs a server plugin with a client mod over a socket protocol, and it is a direct ancestor of **edgeport**. Then **benchmarks** ran the same algorithms in _C, C++, Go, Java, JavaScript, Kotlin, Kotlin/Native, PHP, Ruby, Rust and Zig_. You cannot fake that; it takes idiomatic code in **ten languages at once**.

::insight{icon="i-lucide-package" title="Published to the Grown-Up Registries"}
kasciffy and TabroomAPI to Maven Central. TabroomAPI to npm. gitle to the Gradle Plugin Portal, built so I would stop paying for a hosted repository just to consume my own libraries.
::

:::more{title="The Rest of 2024"}
I founded **Calculus Games**, an indie studio, and designed **LevelZ**, a human-readable file format for game levels with parsers in _six languages_, an IntelliJ plugin, a VSCode extension and a CLI.

By the end of the year I had shipped libraries in three package ecosystems and written production code in ten languages. I was _sixteen_. SocketMC was also the last Minecraft code I wrote, in August 2024.
:::
