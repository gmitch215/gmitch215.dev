Drupal 11 running on Cloudflare Workers, with PHP compiled to WebAssembly inside a Durable Object and that object's own SQLite as the database. No VPS, no container, no origin server, and no PHP extensions dropped to make it fit. A cached page costs 1 ms of Durable Object CPU.
