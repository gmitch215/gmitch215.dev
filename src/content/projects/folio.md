Shared WebAssembly memory and execution parallelism across isolates. A compiler finds independent regions in ordinary WebAssembly, workers run them over one memory, and an ordered validator keeps the serial result. Its report lists the limits beside the results: 7.5x on a compiled C kernel at eight workers on Node, and no speedup for a Drupal render on any backend.
